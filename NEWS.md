# geoprofiler 0.0.4 _2026-08-28_

-  `profile_line()` returns LINESTRING for a set of points

-   `profile_line()` now can interpolate a profile line when the input has more than 2 points.

-   `geoprofiler()` supersedes `profile_coords()` as it sounds more intuitive and is the main function of the package.
